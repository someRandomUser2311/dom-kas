Questions

YAML

Which line is not valid YAML indentation?

metadata:
  name: web
	labels: {}
  1. Line 1
  2. Line 2
  3. Line 3
Line 3 is indented with a tab. YAML never allows tabs for indentation.

In this file, how many containers are defined?

containers:
  - name: api
    image: orders-api:1.0
  - name: proxy
    image: envoy:1.31
    ports:
      - containerPort: 8080
  1. 1
  2. 2
  3. 3
  4. 4
Two items start with - name: at the same indentation. The nested - containerPort belongs to the second container's ports list.

An environment variable must hold the text 8080. Which line is correct?

  1. value: 8080 Unquoted, this is a number; Kubernetes rejects non-string env values.
  2. value: "8080"
  3. value: [8080] That's a list.
Quote values that must stay strings.

Shell

What does set -e do in a Bash script?

  1. Prints each command before running it That's set -x.
  2. Stops the script when a command fails
  3. Exports every variable That's set -a.
Pipelines should always use set -euo pipefail so failures stop the step.

After ID=$(az group show -n rg-orders-dev --query id -o tsv), what does $ID contain?

  1. The full JSON of the resource group
  2. Just the resource group's ID, as plain text
  3. The text az group show …
$(…) captures output; --query id -o tsv makes that output one bare value.

Networking

How many addresses are in 10.0.0.0/22?

  1. 256
  2. 512
  3. 1,024
  4. 4,096
2(32−22) = 210 = 1,024.

Do 10.1.0.0/16 and 10.1.4.0/24 overlap?

  1. Yes, the /24 is inside the /16
  2. No, they have different prefixes
The /16 covers 10.1.0.0–10.1.255.255, which includes 10.1.4.0–10.1.4.255.

A private DNS zone privatelink.azurecr.io is linked to your VNet. Who can resolve names in it?

  1. Anyone on the internet
  2. Only clients using Azure DNS from VNets linked to the zone
  3. Only the registry itself
Private zones resolve only inside linked VNets, or through a DNS forwarder that points to them.

Azure

Order these from the broadest scope to the narrowest.

  1. Management group
  2. Subscription
  3. Resource group
  4. Resource
Access assigned at a scope is inherited by everything below it.

Which role can create resources in a resource group but can't grant access to others?

  1. Owner
  2. Contributor
  3. Reader
  4. User Access Administrator
Contributor has full resource management but no Microsoft.Authorization/*/write.

Which identity type needs no secret and is deleted along with the resource it belongs to?

  1. Service principal with a client secret
  2. System-assigned managed identity
  3. User-assigned managed identity
  4. A user account
A user-assigned managed identity also needs no secret, but it lives on independently of any resource.

Git

Which should be in .gitignore for a Terraform repo?

  1. .terraform/
  2. *.tfstate
  3. .terraform.lock.hcl Commit the lock file.
  4. main.tf
Ignore caches and state; commit code and the lock file.

Kubernetes basics

Which object keeps a set number of identical pods running and replaces them when they fail?

  1. Service
  2. Deployment (through a ReplicaSet)
  3. ConfigMap
  4. Namespace
A Deployment manages ReplicaSets, which keep the desired number of pods running.

How does a Service decide which pods receive its traffic?

  1. By pod name
  2. By a label selector
  3. By the node the pods run on
  4. By the image tag
The Service's selector must match the pods' labels.

A pod shows CrashLoopBackOff. What is the first command you'd run?

  1. kubectl delete node
  2. kubectl logs <pod> --previous (and kubectl describe pod)
  3. kubectl scale --replicas=0
The container keeps crashing; the previous container's logs and the pod's events usually say why.
