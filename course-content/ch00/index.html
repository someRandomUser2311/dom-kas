Chapter 0 · Ready check: placement & refreshers

This chapter is optional. Start with the placement quiz. It takes about 8 minutes and tells you which of the short refreshers below you need. If you already know Kubernetes, it also lets you test out of Chapters 1–3.

Who this course assumes you are

We assumeWe don't assume
  • You're comfortable on a command line: running commands, files, pipes, environment variables.
  • Basic Git: clone, commit, push, branch, pull request.
  • You know what an IP address and a port are.
  • You've seen the Azure portal.
  • Kubernetes
  • Docker beyond "heard of it"
  • YAML
  • CIDR maths
  • How subscriptions, Entra ID and RBAC fit together
  • Any programming. The app code is always given.
