Write lab: the supply-chain stage

Brief: Extend the Build stage of azure-pipelines.yml and the prod deploy. Graded by pipeline-rules.

  • A scan step runs before push (or before signing and deploy), and fails on fixable HIGH/CRITICAL (--exit-code 1, --severity HIGH,CRITICAL, --ignore-unfixed).
  • An SBOM is generated (SPDX or CycloneDX) and attached or published.
  • A signing step uses a WIF service connection (AzureCLI@2 + notation sign with the Key Vault plugin) on the image digest.
  • No signing key material in the repo or YAML (no .key or .pem files, no inline private keys).
  • The deploy references the image by digest (@sha256: or a digest variable from the build).
  • Sign comes after scan.
Reference solution (outline)

Lesson 16.3, step 2 (build, scan, push), plus a step capturing the digest as an output variable, the SBOM steps from 16.3 steps 7–8, the signing step from 16.4, step 4, and containers: contosoacr.azurecr.io/orders-api@$(imageDigest) in the deploy task.

Walkthrough: scan fails → fix → sign → admission verifies

  1. The build of 1.6.0 fails the scan: CRITICAL in libssl (the runtime stage was Debian-based).
  2. Switch the runtime to distroless; rescan: 0 findings.
  3. Push, attach the SBOM, notation sign with the Key Vault key.
  4. Deploy by digest; admission verifies the signature and policies, and the pods run.
  5. Try to deploy an unsigned test image: denied, with the policy message.

Try it locally

16.2 Image sizes.

cd lab/examples/ch16
docker build -f Dockerfile.single -t localhost:5001/oa:single .
docker build -f Dockerfile.distroless -t localhost:5001/oa:distroless .
docker images localhost:5001/oa

Expected: roughly 800 MB vs about 15 MB.

Cleanup: docker rmi localhost:5001/oa:single localhost:5001/oa:distroless

16.3 Scan and SBOM.

trivy image --severity HIGH,CRITICAL --ignore-unfixed localhost:5001/oa:single
trivy image --severity HIGH,CRITICAL --ignore-unfixed localhost:5001/oa:distroless
trivy image --format spdx-json -o sbom.json localhost:5001/oa:distroless && head -c 300 sbom.json

Expected: findings for the single-stage image and few or none for distroless; an SPDX document.

Cleanup: rm sbom.json

16.4 cosign sign and verify.

docker push localhost:5001/oa:distroless
DIGEST=$(docker inspect --format='{{index .RepoDigests 0}}' localhost:5001/oa:distroless)
cosign generate-key-pair && cosign sign --key cosign.key --tlog-upload=false "$DIGEST"
cosign verify --key cosign.pub --insecure-ignore-tlog "$DIGEST"

Expected: "Verification for … The cosign claims were validated". (The transparency log is skipped for the local lab.)

Cleanup: rm cosign.key cosign.pub

16.5 Kyverno allowed registries.

./lab/addons/kyverno.sh
kubectl apply -f lab/examples/ch16/allowed-registries.yaml      # allows localhost:5001/ only
kubectl run bad --image=docker.io/library/nginx:1.27
kubectl run good --image=localhost:5001/oa:distroless

Expected: bad is denied ("Images must come from …"); good is created.

Cleanup: kubectl delete pod good; kubectl delete -f lab/examples/ch16/allowed-registries.yaml
