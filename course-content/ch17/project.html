Chapter 17 · Capstone project (multi-file write lab)

Ship Contoso Orders to production

Build the complete repository in the multi-file editor and pass the readiness review: ≥ 80% with no critical rule failing. Choose Terraform (infra/terraform/) or Bicep (infra/bicep/) at the start. Submitting both earns the "Bilingual IaC" badge.

Scoring

  • Each file is weighted (lesson 17.4); the project is 100% of the chapter score.
  • Pass at 80% with no critical rule failing.
  • Viewing the reference solution caps the project at 60%.
  • The results page shows a readiness report: each failed rule with file, line and a link to its lesson.

Reflection (not graded)

A short text box: "If the budget halved, what would you change in the architecture, and what risk would you accept?" (lesson 17.2, step 9).

Optional local smoke test

Apply the dev overlay, policies and gateway to the kind lab (with the Chapter 8, 9 and 16 add-ons installed), then:

./lab/smoke.sh

It checks:

  • the rollout completes;
  • the route answers /api/healthz;
  • default-deny holds (web → db is blocked);
  • restricted Pod Security is enforced (a privileged test pod is rejected).

It's never graded. Infra and pipeline files are graded in the browser only.

Cleanup: ./lab/smoke.sh --cleanup
