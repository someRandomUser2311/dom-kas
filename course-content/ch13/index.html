Chapter 13 · Infrastructure as code with Bicep

The same Contoso platform as Chapter 12, now in Bicep, Azure's own IaC language. Every concept step has a "Coming from Terraform" tab, so you map what you know rather than starting over. You can still follow this chapter on its own if you skipped Chapter 12. Files go in infra/bicep/.

By the end, you can

  • Explain how Bicep relates to ARM: it compiles to ARM JSON, Azure itself is the state, and resources have API versions.
  • Write Bicep fluently: param with decorators, var, output, symbolic names, existing, parent, loops, conditions, user-defined types and .bicepparam files.
  • Build the Contoso platform: VNet, ACR, AKS (+ user pool), Log Analytics, role assignments, and a workload identity with a federated credential.
  • Use deployment scopes (targetScope), modules, Azure Verified Modules and a private module registry in ACR.
  • Preview with what-if; understand incremental vs complete mode; manage lifecycle with deployment stacks.
  • Run Bicep in Azure Pipelines, and choose between Bicep and Terraform.
